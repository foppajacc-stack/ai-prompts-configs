# ai-prompts-configs

A collection of AI prompts, system instructions, and configs for Claude, Perplexity, Grok, and Kimi.

## Folder Structure

```
ai-prompts-configs/
├── claude/
│   └── system-prompt.md
├── perplexity/
│   └── search-prompts.md
├── grok/
│   └── prompts.md
└── kimi/
    └── prompts.md
```

## How to Use

1. Browse the folder for your AI platform
2. 2. Copy the prompt you want
   3. 3. Paste it into the AI's system prompt or chat box
      4. 4. Customize as needed
        
         5. ## Platforms
        
         6. | Platform | Folder | Use for |
         7. |---|---|---|
         8. | Claude | `/claude` | Deep research, writing, coding |
         9. | Perplexity | `/perplexity` | Web search, up-to-date answers |
         10. | Grok | `/grok` | Real-time X/Twitter data, news |
         11. | Kimi | `/kimi` | Long documents, Chinese content |
