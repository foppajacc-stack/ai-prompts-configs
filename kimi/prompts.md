# Kimi Prompt Templates

Use these prompts with Kimi (Moonshot AI) for long documents, complex PDFs, and multilingual tasks.

---

## Long Document Summarizer

```
I am uploading a long document. Please:
1. Provide an executive summary (3-5 bullet points)
2. Identify the 5 most important sections or arguments
3. Highlight any action items or key decisions mentioned
4. Flag any contradictions or unclear sections
```

---

## PDF Research Extractor

```
From the uploaded PDF/document:
- Extract all key statistics, figures, and data points
- List all named entities (people, companies, places)
- Summarize methodology (if academic paper)
- Provide a one-page executive brief suitable for sharing with leadership
```

---

## Multilingual Translation Assistant

```
Translate the following text from [SOURCE LANGUAGE] to [TARGET LANGUAGE].
Requirements:
- Maintain the original tone and formality level
- Keep technical terms accurate
- Note any culturally specific phrases that don't translate directly
- Provide alternate phrasings for ambiguous passages
```

---

## Document Q&A Mode

```
I will upload a document. Act as a knowledgeable assistant about its contents.
When I ask questions:
- Answer based strictly on the document's content
- Quote relevant passages when helpful
- If the answer is not in the document, say so clearly
- Do not make assumptions beyond what is written
```

---

## Contract and Legal Review

```
Review the uploaded contract/agreement and:
- List all obligations for each party
- Highlight unusual or potentially risky clauses
- Summarize key dates and deadlines
- Note any missing standard clauses that should be present
- Flag ambiguous language that may need clarification
```
